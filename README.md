### Project Description
SkreenshotX is a harmless prank application designed to look like a normal screenshot-saving tool. It creates a convincing saving experience and, just when the user expects the screenshot to be successfully saved, reveals the truth with a surprise prank message.

The project turns a completely ordinary screenshot-saving task into a small, unexpected moment of fun.

    
### The Problem (that doesn't exist)
Have you ever worried that saving a screenshot is *too straightforward and boring*?

There was absolutely no real problem to solve. So naturally, we decided to create one:

> *"What if saving a screenshot could waste a few seconds of someone's life before revealing that they have been pranked?"*

### The Solution (that nobody asked for)
We created *Fake Screenshot Saver*.

The application imitates a normal screenshot-saving process. It gives the user the impression that their screenshot is being processed and saved. At the end of the process, instead of completing the save operation, it delivers the completely unnecessary but important message:

> 🎉 *CONGRATULATIONS! YOU HAVE BEEN SUCCESSFULLY PRANKED!* 🎉

No files are damaged, no data is deleted, and no serious purpose is accomplished.

Exactly as intended.
